Project Architecture Documentation

This document provides a comprehensive overview of how this Next.js web application operates. It breaks down the optimal folder structure we implemented, detailing what every folder and file is responsible for.

1. Core Application Routing

src/app/

This is the heart of the Next.js App Router. It handles all page routing, global layouts, and server-side logic.

  • layout.tsx The root wrapper for the entire application. It imports global fonts, sets up HTML/Body tags, and wraps the app in global providers (like SmoothScroll and Navigation).
  • page.tsx The main landing page (Home). This file brings together various sections (Hero, Overview, Contact) to build the main view.
  • globals.css / home.css Global stylesheets containing fundamental CSS variables, Tailwind directives, and complex keyframe animations.
  • api/ Directory for Next.js API Routes (serverless backend functions).
  • about/, projects/, skills/ Directories representing the `/about`, `/projects`, and `/skills` routes respectively. Each contains its own `page.tsx`.

2. User Interface Components

The src/components/ directory has been highly modularized to separate concerns, making the app scalable and maintainable.

src/components/layout/

Structural components that define the global skeleton of the application.

  • Navigation.tsx The main pill-shaped navigation menu containing the theme toggle and routing links.
  • TopBar.tsx The top header bar (if used) spanning the top of the screen.
  • Socials.tsx Floating social media icons (GitHub, LinkedIn) typically anchored to the sides.
  • Preloader.tsx The initial loading screen that runs before the React tree fully mounts, managing the initial perceived performance.

src/components/sections/

Massive, logical content blocks that make up the structure of a page.

  • Hero.tsx The opening viewport of a page containing the main focal typography and imagery.
  • Overview.tsx A generalized section for text/introductory content.
  • TechMatrix.tsx A complex section displaying skills and technical capabilities.
  • Contact.tsx The footer section featuring email/social links and the final call-to-action.
  • CaseStudySections.tsx Deep-dive layouts for explaining individual project structures.
  • StackedProjects.tsx The luxury editorial layout showing project images and text split in a 55/45 grid.

src/components/visuals/

Highly complex graphical components, Canvas elements, and heavy animations.

  • KineticTunnel.tsx A dynamic, math-driven background visual effect.
  • GithubGraph.tsx A custom visualization rendering GitHub contribution activity.
  • IconCloud.tsx An interactive 3D sphere of floating technology icons.
  • GoldenTrail.tsx A mouse-following interaction effect.
  • ScrollLogo.tsx A logo that reacts and transforms based on scroll position.
  • TunnelOverlay.tsx An overlay specifically tailored for background interactions.

src/components/ui/

Small, reusable, independent utility components.

  • CustomCursor.tsx Overrides the default browser cursor with a custom React-tracked element.
  • SmoothScroll.tsx Implements Lenis or a similar library to hijack native scrolling for a buttery smooth experience.
  • PageTransition.tsx Framer Motion wrappers to animate routes in and out seamlessly.
  • ScrollToTop.tsx A utility button that returns the user to the top of the viewport.
  • ScrambleText.tsx A specialized text effect component (e.g., hacker/matrix decoding effect).

3. Application Logic & Utilities

src/hooks/ & src/lib/

The brains and data layers of the application.

  • src/hooks/useTheme.ts A custom React Hook that manages state between Light and Dark mode, persisting user preference in localStorage.
  • src/lib/stream-chat.ts A utility file containing backend API clients, database connections, or 3rd-party integrations (like GetStream).

4. Root Configurations

Root Directory

Configuration files required by Node, Next.js, and Tailwind.

  • package.json Defines all the external libraries (dependencies) installed via npm and the build scripts.
  • next.config.ts Configuration specific to Next.js (e.g., Turbopack, image domains, redirects).
  • tsconfig.json Tells TypeScript how strictly to enforce typing across the project.
  • eslint.config.mjs Linter configuration to enforce code quality and formatting standards.
